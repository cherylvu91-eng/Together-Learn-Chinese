\# Together Learn Chinese



Web tĩnh tra cứu từ vựng tiếng Trung theo cấp độ HSK, dành cho học sinh.



\## Tính năng

\- Tìm kiếm theo chữ Hán / pinyin / nghĩa tiếng Việt

\- Lọc theo cấp độ HSK

\- Flashcard ôn từ vựng

\- Trắc nghiệm

\- Xem thứ tự nét chữ (HanziWriter)



\## Cập nhật từ vựng

1\. Mở file `vocab\_data.xlsx`, thêm/sửa dòng dữ liệu.

2\. Chạy `python convert\_excel\_to\_json.py` để tạo lại `data/vocab.json`.

3\. Commit và push lên GitHub, trang web sẽ tự cập nhật.
